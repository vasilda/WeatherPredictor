# WeatherPredictor

## Описание проекта
Основная задача — предсказание значений целевых переменных (температура, влажность) на основе их прошлых значений с использованием лаговых признаков и скользящих статистик.

### Структура проекта
```text
project/
├── model.py                # Основной класс модели с двумя режимами работы (краткосрочное и долгосрочное предсказания) + пример
├── review.ipynb            # Блокнот с подробным описанием выполненных действий: от предобработки данных до построения и тестирования модели
├── dataset.csv             # Исходный набор данных
├── clear_dataset.py        # Предобработанный датасет
├── weather_predictor.pkl   # Обученная модель
├── requirements.txt        # Зависимости
├── README.md               # Документация
```

### Этапы предобработки данных
1. Разбитие timestamp на год, месяц, день, время.
2. Обработка пропусков (замена на среднее в зависимости от месяца и года).
3. Обработка выбросов (при наличии большого % аномалий от других значений).
4. Анализ корреляции признаков.
5. Вычисление лаговых признаков и скользящих статистик.

### Обучение модели
1. Разделение данных на тренировочную и тестовую выборки (по времени, т.е. обучаем на самых ранних датах).
2. Выбор baseline (XGBoost).
3. Обучение и тестирование.
4. Подбор гиперпараметров.

### Метрики качества:
1. RMSE — среднеквадратичная ошибка.
2. MAE — средняя абсолютная ошибка.
3. R2 — коэффициент детерминации.

### Методы класса
|        Метод        |	                 Назначение                       |
| ------------------- | ------------------------------------------------- |
| prepare_features()  |	Создание лаговых признаков и скользящих статистик |
| train()             |	Обучение модели XGBoost с мультитаргет-оболочкой  |
| predict_next_hour() |	Прогноз на 1 час вперед                           |
| predict_24_hours()  |	Рекурсивный прогноз на 24 часа                    |
| evaluate()          |	Оценка качества на тестовой выборке               |
| save_model()        |	Сохранение модели в файл (.pkl)                   |
| load_model()        | Загрузка сохраненной модели                       |

### Процесс обучения для модели из класса
1. Подготовка признаков через prepare_features().
2. Выделение таргетов (temperature, humidity).
3. Удаление последней строки (из-за сдвига).
4. Разделение на train/test (80/20 с сохранением временной структуры).
5. Обучение модели XGBoost через MultiOutputRegressor.
6. Расчет метрик на тестовой выборке.
7. Сохранение истории для последующего использования.

### Процесс прогнозирования
#### predict_next_hour():
1. Подготовка признаков для всего history (данные до T).
2. Выбор последней строки для прогноза.
3. Прогноз через обученную модель.
4. Возврат словаря с temperature и humidity

#### predict_24_hours() (рекурсивный):
На каждом шаге (24 итерации):
1. Подготовка признаков на основе текущей history (данные до T).
2. Прогноз на 1 час вперед.
3. Создание новой строки с прогнозом.
4. Добавление строки в history c обновление временных меток (+1 час).
5. Повтор действий, но уже относительного нового T.

Результат: список прогнозов с временными метками.

## Недостатки реализации
1. Заморозка дополнительных признаков при предсказании на 24 часа. То есть pressure, wind_speed, production_level, maintenance, power, tariff_enc просто копируются из последней строки.
2. Накопление ошибок при рекурсивном прогнозировании.

Стоит добавить кросс-валидацию типа ExpandingWindowSplitter.
